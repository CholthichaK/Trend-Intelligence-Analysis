# Trend-Intelligence-Analysis

📌 Overview
This project is an AI-powered system that analyzes social media trends and generates viral content ideas for media companies.

## 🚨 Problem
Media teams often react too late to trends, missing engagement opportunities.

## 💡 Solution
This system uses Claude AI to:
- Analyze trending topics
- Identify viral patterns
- Generate platform-specific content ideas

## ⚙️ Workflow
1. Collect trends from TikTok, YouTube, and Instagram
2. Store data in Google Sheets
3. Input trends into Claude AI
4. Generate insights and content ideas
5. Store results for content planning


## Prompt: 
"
You are an AI Trend Analyst working for a media company.
Your job is to analyze trending topics and generate actionable content ideas.
For each trend:
1. Explain why it is trending
2. Identify the target audience
3. Give a viral score (1–10)
Then generate:
- 3 viral content ideas
- Platform (TikTok, YouTube, Instagram)
- A strong hook (attention-grabbing first line)
Keep answers concise, practical, and business-focused.
Also rank the trends from highest to lowest viral potential.
Create a 3-day posting plan based on these trends.
Competitor video: “Top AI Tools” – 200K views


Here is the trend data:
## (Insert Data)
"
